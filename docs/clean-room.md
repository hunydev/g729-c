# Clean-Room Boundary

`g729-c` is a C port of the clean-room Go implementation in
`/home/exedev/g729`.

Allowed implementation inputs:

- Go source in `/home/exedev/g729`.
- Public README/docs/tests in `/home/exedev/g729`.
- Numeric or byte fixtures generated by running the Go implementation.
- Original C code written in this repository.

Forbidden implementation inputs:

- ITU reference C.
- `bcg729`.
- FFmpeg G.729 encoder/decoder source.
- Sipro implementations.
- Asterisk/FreeSWITCH G.729 codec modules.
- Sangoma or other commercial G.729 codec modules.
- Any other existing G.729 implementation source.

The sibling Go repository is read-only for this effort. Generated oracle
fixtures are written into this repository only.

The project may claim Go-port equivalence only for behavior covered by tests
that compare against committed Go-generated fixtures.

Current generators:

- `tools/oracle-gen` writes public encoder/decoder/loopback fixture JSON.
- `tools/port-lsp-tables` writes C LSP table source from the Go table package.
- `tools/lsp-oracle` writes exact LSP/LP stage vectors for C tests.
- `tools/pitch-oracle` writes exact adaptive-codebook stage vectors for C
  tests.
- `tools/fcb-oracle` writes exact fixed-codebook stage vectors for C tests.
- `tools/port-gain-tables` writes C gain table source from the Go table
  package.
- `tools/gain-oracle` writes exact gain decoder vectors for C tests.
- `tools/gain-quant-oracle` writes exact encoder gain quantization vectors
  for C tests.
- `tools/synth-oracle` writes exact synthesis-stage vectors for C tests.
- `tools/hp-oracle` writes exact output high-pass filter vectors for C tests.
- `tools/postfilter-oracle` writes exact stateful postfilter vectors for C
  tests.
- `tools/decode-oracle` writes full-frame decoder vectors from Go
  `Decoder.DecodeFrame` for C API tests.
- `tools/encode-oracle` writes full-frame encoder vectors from Go
  `EncoderProfileCore` for C API tests.
- `tools/pcm-oracle` writes exact encoder preprocessor vectors for C tests.
- `tools/lpc-oracle` writes exact LPC analyzer vectors for C tests.
- `tools/lsp-enc-oracle` writes exact encoder LSP front-end and VQ sequence
  vectors for C tests.
- `tools/openloop-oracle` writes exact encoder open-loop pitch search vectors
  for C tests.
- `tools/closedloop-oracle` writes exact encoder closed-loop pitch vectors for
  C tests.
- `tools/fcb-search-oracle` writes exact encoder fixed-codebook search vectors
  for C tests.
